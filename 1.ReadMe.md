<!-- ICANN -->

- ICANN, or the Internet Corporation for Assigned Names and Numbers, 
- It is a non-profit organization that coordinates the maintenance of the Internet's technical infrastructure, specifically the domain name system (DNS) and IP address allocation. 
- Its main role is to ensure the internet remains stable and secure by managing these critical resources so that every website and device has a unique address and can be reliably located.

<!-- WHOIS -->
WHOIS is a query and response protocol that is used for querying databases that store an Internet resource's registered users or assignees. These resources include domain names, IP address blocks and autonomous systems, but it is also used for a wider range of other information.

<!-- ICANN vs WHOIS -->
- ICANN is the organization that regulates the internet's domain name system, 
- while WHOIS is the public protocol and database it oversees for retrieving domain registration information. 
- Essentially, ICANN makes the rules for domain registration, 
- and WHOIS is the publicly accessible directory of that information, which is managed by ICANN-accredited domain registrars.
